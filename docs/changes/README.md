# Change Records

Folder ini menyimpan snapshot / ringkasan setiap batch perubahan fitur — biasanya satu PR atau satu milestone.

## Konvensi

- Penamaan file: `YYYY-MM-DD-<slug>.md` (kebab-case)
- Setiap file mencatat:
  - **Tanggal** & **status** (merged / in progress / archived)
  - **Tujuan** perubahan (kenapa, problem apa)
  - **File** & **commit** terkait
  - **Verifikasi** yang sudah dilakukan

> Detail histori lengkap tetap ada di `git log`. File di sini hanya snapshot ringkas untuk navigasi cepat dan onboarding.
